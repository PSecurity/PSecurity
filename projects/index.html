CASE STUDIES

Projetos apresentados por problema, solução e stack
BLK
PS.Block

Problema: estudar e organizar proteção local de recursos sensíveis do Android em dispositivos próprios e ambientes autorizados. Solução: aplicativo Android open source com foco em câmera, microfone, localização, Bluetooth, Device Admin, watchdog, app lock, logs locais e políticas de proteção.

Android Kotlin Publicado
GitHub
CHAT
PS.Chat Admin / PS.Chat CLI

Problema: organizar comunicação privada em ambiente local/offline com controle, moderação e foco em segurança. Solução: servidor administrativo e cliente terminal com salas, comandos, descoberta em rede local, histórico local criptografado e recursos de E2EE.

Python CLI Segurança
GitHub
KIT
PS.Toolkit v2

Problema: centralizar utilitários técnicos usados em estudos, automação e segurança mobile. Solução: toolkit web local para Termux com módulos de Nmap, DNS, hash, senhas, notas, túneis, Linux manager e apoio técnico.

Python Flask Termux
GitHub
NOTE
PS.Notes

Problema: registrar comandos, snippets, estudos e rascunhos técnicos com rapidez durante fluxos de trabalho em terminal. Solução: bloco de notas autoral com editor, split view, snippets, salvamento local, cópia e exportação.

HTML CSS JavaScript
Open
M5
DoomStickC M5StickC Plus2

Problema: explorar limites de dispositivo embarcado pequeno com renderização, controles físicos, IMU, áudio e lógica interativa. Solução: protótipo retro FPS em C++ para M5StickC Plus2, com mapas, HUD, inimigos, armas, áudio e estrutura modular.

C++ ESP32 PlatformIO
GitHub
NMAP
PS.Nmap

Problema: facilitar estudos de reconhecimento de rede em ambientes móveis e autorizados. Solução: menu educacional para Nmap no Termux, com host discovery, portas, versões, sistema operacional, NSE e scans personalizados.

Shell Script Nmap Termux
GitHub
GRD
PS.Guardian

Problema: organizar auditorias, evidências, relatórios e fluxos técnicos em uma experiência mobile mais profissional. Solução: app em desenvolvimento para evidências, findings, sessões de auditoria, relatórios, checklists e apoio a ambientes autorizados.
